Student Grade Manager

A Java Swing-based desktop application for managing student grades and generating a simple class summary report.

Features

* Add student names and marks
* Store student data using ArrayList
* Automatically calculate:
    * Class Average
    * Highest Score
    * Lowest Score
    * Total Students
* Automatically assign grades based on marks
* Display student details in a table
* Show performance descriptions for each grade
* Delete selected student records
* Clear input fields
* Input validation for names and marks
* Attractive and user-friendly graphical interface

Grade System

Marks	Grade	Performance
90–100	A+	Excellent
80–89	A	Very Good
70–79	B	Good
60–69	C	Average
50–59	D	Needs Improvement
Below 50	F	Fail

Technologies Used

* Java
* Java Swing
* Java AWT
* ArrayList
* JTable
* DefaultTableModel

How to Run

Make sure Java is installed on your system.

Compile the program:

javac StudentGradeManager.java

Run the application:

java StudentGradeManager
